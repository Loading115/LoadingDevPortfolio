# Loading Dev Portfolio

React Single Page Application for my Game Developer Portfolio.  
Showcasing projects, devlogs, and my journey as an indie game developer.

---

## Tech Stack

- React
- Vite
- TypeScript
- Tailwind CSS
- shadcn/ui
- React Router

---

## Installation

### 1 Clone the repository

```bash
git clone https://github.com/Loading115/LoadingDevPortfolio.git
cd LoadingDevPortfolio

2 Install dependencies
npm install

3 Run the development server
npm run dev

The app will be available at:

http://localhost:5173
```
